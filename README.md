# Marcel Mendes - Portfolio

A modern, beautifully designed portfolio website built with Next.js and React.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** CSS Modules

## Color Palette

- Background: Deep charcoal blacks (`#0a0908`, `#1a1816`)
- Accent: Warm terracotta (`#e07a5f`)
- Secondary Accent: Amber gold (`#d4a574`)
- Text: Soft cream (`#f4f1ed`)
